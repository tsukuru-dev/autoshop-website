# autoshop-website

Astro website for FJD Autos, with static service pages and a Cloudflare Worker enquiry endpoint.

```sh
npm install
npm run dev
```

See [development and Cloudflare setup](docs/SETUP.md) for the folder structure, email configuration,
verification commands and launch checklist. Business content is provisional; the enquiry form
stays disabled until a Turnstile site key is configured, and the backend rejects submissions
until its email and verification settings are present.
